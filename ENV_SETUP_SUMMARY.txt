🚀 QUICK START - COPY & PASTE
────────────────────────────────────────────────────────────────────────────────

Option 1: SQLite (Development - Simplest)
──────────────────────────────────────────
export ENCRYPTION_KEY=$(node src/cli-store.js generate-key)
node src/cli-store.js set API_KEY "test"
node src/cli-store.js get API_KEY


Option 2: SSH File Storage (Remote - Your Server)
──────────────────────────────────────────────────
ssh -i /Users/user/.ssh/id_rsa ubuntu@134.185.111.151 "echo OK"
export ENCRYPTION_KEY=$(node src/cli-store.js generate-key)
export SSH_HOST="134.185.111.151"
export SSH_USER="ubuntu"
export SSH_KEY="/Users/user/.ssh/id_rsa"
export REMOTE_DB_PATH="/home/ubuntu/env-secrets.json"
node examples/ssh-storage.js


Option 3: Firebase (Cloud - Auto-scaling)
──────────────────────────────────────────
npm install firebase-admin
export ENCRYPTION_KEY=$(node src/cli-store.js generate-key)
export FIREBASE_PROJECT_ID="your-project"
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/key.json"
node examples/firebase-storage.js

🔑 GENERATING VALUES
────────────────────────────────────────────────────────────────────────────────

Encryption Key:
  node src/cli-store.js generate-key
  └─ Creates 32-byte base64 string
  └─ Copy output to ENCRYPTION_KEY

Firebase Service Account Key:
  1. https://console.firebase.google.com
  2. Settings (⚙️) → Service Accounts
  3. Generate New Private Key
  4. Save JSON file
  5. Set GOOGLE_APPLICATION_CREDENTIALS to file path

SSH Key:
  ssh-keygen -t ed25519 -f ~/.ssh/id_rsa
  └─ Or use existing: /Users/user/.ssh/id_rsa
